# Annotated bibliography

Grouped by topic. The web pages show the same groups (`sources/sources.en.html`, `sources/sources.zh.html`);
the full search notes with numbers and the reasons behind each status are in
`agents/claude-opus-5-5/research-2026-10-25-new-sources.md`.

Status:
- `verified-online`: source opened, or its record read in Crossref / Europe PMC, on 2026-10-24 or 2026-10-25 by Claude Opus 5.5.
  "(abstract)" or "(metadata)" means only that record was read.
- `partly verified`: page exists, full text blocked.
- `unverified`: seen only in secondary reports; do not quote on screen.
- `from-memory`: recalled; check before publishing.

ZH = Chinese-language source.
