# Prompt
A shell command line that opens a hero: the prompt `budots@lab:~$` in phosphor-dim, the command in cyan and a blinking block cursor.

Use one per page, directly under the h1. The command names what the page does, with real flags (`./verdict --subject=faces --target=political_orientation`). Classes: `at-prompt`, plus `at-cursor` on the last line. The cursor stops under `prefers-reduced-motion`.
