# ConsoleBand
A full-width band with a numbered eyebrow label, a bold uppercase mono heading and running text in a column at most 70ch wide, over a faint ghost word.

The eyebrow number encodes the reading order. Put one ghost word per band (a unit or symbol from the content: AUC, 50%, P(x)) at `opacity-ghost`. Classes: `at-band`, `at-console`, `at-tiny`, `at-h2`, `at-ghost`, `at-hl` for one highlighted phrase.
