# Data policy

- `raw/` holds files received from the PI. They are **not analysed for
  personal traits** (political, sexual orientation, personality, etc.) by any
  agent. See `docs/00-scope-and-ethics.md`.
- `raw/865483837_2216210599005726_4764690777250093474_n.jpeg` was received
  2026-10-24 and moved here from the project root. It is a Visegrad24
  social-media quote graphic of journalist Mehdi Hasan (third-party
  copyright), not a photo of the PI. Agents must not classify it or use it
  in published material.
- Don't commit personal photos to any public repo.
- Datasets added later must include source, license and consent basis in a
  `DATASET.md` next to them.
